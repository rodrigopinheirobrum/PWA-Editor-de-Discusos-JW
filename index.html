Conexão e envio automático

Como obter o ID do cliente (grátis)
  1. Em console.cloud.google.com, crie um projeto e ative a Google Drive API.
  2. “Tela de permissão OAuth”: tipo Externo; em “Usuários de teste” inclua o seu e-mail.
  3. “Credenciais › ID do cliente OAuth › Aplicativo da Web”. Em “Origens JavaScript autorizadas” coloque: (sem barra no fim).
  4. Copie o ID do cliente e cole acima. O acesso pedido é o mínimo (drive.file e drive.appdata): só enxerga o que a ferramenta cria e a pasta privada dela na sua conta. Na “Tela de permissão”, se pedir escopos, inclua esses dois.

Se você já criou à mão uma pasta com esse nome, o Google não a mostra à ferramenta (por segurança): ela cria a dela com o mesmo nome.

        Serviço próprio (avançado, grátis): o jeito mais confiável

        Os serviços públicos caem ou mudam. Um serviço seu, de 10 linhas no Cloudflare Workers (grátis, sem cartão), só lê páginas e imagens do jw.org e não depende de terceiros: crie um Worker, cole o código abaixo, publique e cole aqui o endereço dele terminado em ?url=.

        export default {
  async fetch(request) {
    const alvo = new URL(request.url).searchParams.get('url') || '';
    let u; try { u = new URL(alvo); } catch { return new Response('url inválida', { status: 400 }); }
    if (!/(^|\.)(jw\.org|jw-cdn\.org|akamaihd\.net)$/i.test(u.hostname)) return new Response('só jw.org', { status: 403 });
    const r = await fetch(u.href, { headers: { 'User-Agent': 'Mozilla/5.0', 'Accept-Language': 'pt-BR,pt;q=0.9' } });
    return new Response(r.body, { status: r.status, headers: { 'Content-Type': r.headers.get('Content-Type') || 'text/html; charset=utf-8', 'Access-Control-Allow-Origin': '*' } });
  }
};

          Como o esboço se liga aos parágrafos do JW Library?

          O JW Library guarda notas pessoais separadas da publicação, ligadas só por um número de parágrafo (§) — o app junta as duas coisas ao abrir a publicação oficial. No S-34, o título é o §1 e a linha “Nota ao orador:” forma um único §2 com o texto que vem logo abaixo; daí em diante cada bloco é um § (o botão ao lado do número agrupa um bloco-rótulo com o seguinte). Ao carregar o .jwpub, a ferramenta confere o total de parágrafos. O texto do esboço nunca vai no .jwlibrary.

          Destaques, negrito e sublinhado só funcionam no modo leitura (esboço e notas, pela barra que aparece junto da seleção) e são só para o seu estudo: ficam salvos automaticamente no rascunho do navegador e no .html/PDF, e voltam ao reabrir o .html. O JW Library não tem destaque dentro do texto de uma nota, então no .jwlibrary vai o texto simples (a cor da nota, em cima, continua indo). Ocultar parágrafo (o olho ao lado do §) esconde o parágrafo e suas notas da leitura e do PDF, mas ele continua no arquivo .html e no .jwlibrary.

          Ler e editar: o botão redondo do canto da tela troca de modo: na leitura mostra o lápis verde (um toque e você volta a editar) e, na edição, o livro (um toque e você vai para o modo leitura). Ele acompanha o tema claro/escuro. Rodapé: ao lado dele ficam, no pé da tela, o botão Controles (mostra/oculta a barra fina de ferramentas: cada ícone abre um menu — abrir, exportar, salvar, exibição e mais), o botão Quadro de notas (mostra/oculta o quadro com contagem, “Ir ao §” e “Gerenciar notas” — é um comando separado, funciona também na leitura), o tema claro/escuro, a fonte (+ / −) e, na leitura, os números dos parágrafos. Nas cores das notas, a leitura mostra a cor escolhida também no tema claro. Ao abrir a ferramenta, ela pergunta se você quer continuar de onde parou: respondendo “Sim”, o último backup e o último esboço guardados neste navegador são carregados sozinhos (“Esquecer arquivos guardados” apaga essa cópia).

          Referências: um texto bíblico (ícone de livro, verde) abre direto no aplicativo JW Library; uma fonte de matéria (ícone de lupa, dourado e pontilhado) é pesquisada no wol.jw.org. No modo leitura o toque abre na hora; ao editar, um aviso pergunta antes. Se o app não abrir, aparece a opção “Ler no wol.jw.org”.

          Imagens: o botão ao lado de cada parágrafo coloca uma imagem logo abaixo dele, como parágrafo identado (recuo, tamanho e legenda ajustáveis). Elas vão no “Esboço final .html” e no PDF — somente quando “Texto” está marcado — e não vão no .jwlibrary.

          Guardar e instalar: “Esboço final .html” baixa o arquivo; “Guardar no Drive” envia esse mesmo arquivo para a pasta “Discursos JW” do seu Google Drive (exige abrir a ferramenta por um endereço https e configurar o ID do cliente na engrenagem; o botão “Compartilhar” é a alternativa sem configuração). “Instalar app” coloca a ferramenta na tela inicial, também por https.
